# v1 — S0-S4 video-to-image SSL series

Lives in `data/v1/` and in the internvl-u submodule's `shell/internvlu/{sft,orchestration}/v1/`.
Git tag `v1` pins the same content in its pre-split layout (see [`VERSIONS.md`](VERSIONS.md)).
Exact file-level provenance: [`../PROVENANCE.md`](../PROVENANCE.md). Narrative walkthrough:
[`PIPELINE.md`](PIPELINE.md). This page is the summary.

## Settings

All five use **3 ordered context frames → 1 generated frame** on a shared sampling grid:
`SAMPLE_FPS = 2.0` (0.5 s spacing), target 1 grid step (0.5 s) after the last context frame.
NWM is the exception: native 4 fps, context 0.25 s apart, target still 0.5 s ahead. VBVR uses a
duration-adaptive gap (0.5 / 0.75 / 1.0 s).

| Setting | Name | Input | Target | Text supervision | `LM_LOSS_WEIGHT` |
|---|---|---|---|---|---|
| S0 | V2I-F | 3 frames | next frame | — | 0.0 |
| S1 | V2I-V | 3 frames | next **or** preceding frame (stated in prompt) | — | 0.0 |
| S2 | VC2I-F | 3 frames + caption | next frame | — | 0.0 |
| S3 | VC2IA-F | 3 frames + caption + 4 candidate images | next frame | 4-way MCQ answer letter | 0.5 |
| S4 | VC2IC-F | 3 frames + caption | next frame | progression description + next-frame text prediction (VLM-labeled) | 0.5 |

The 5 stage-1 runs are independent (all from the same base snapshot, not chained).

## Training

Launchers are under `training/models/internvl-u/internvl_chat/shell/internvlu/`:

- Stage 1: `sft/v1/run_s{0..4}_gen_sft.sh` →
  `/scratch/network/ssd2/junlin/models/internvlu-s{0..4}-gen(-merged)`.
- Stage 2 (VBVR target-pred, 4 tasks × 500): `sft/v1/run_target_pred_mop_sft.sh` on each
  stage-1 checkpoint (and base) →
  `/scratch/network/ssd/junlin/models/internvlu-{base,s0..s4}-4task500sft(-merged)`.
