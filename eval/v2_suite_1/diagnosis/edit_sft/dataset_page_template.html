Edit-SFT probe set

The small instruction-editing dataset used to fine-tune base, T0, T2 and T3 with one identical recipe. It tests whether the trained models only lack the editing format. Every pair below is exactly what the trainer saw: the input image, the instruction text and the target image.

SourcesStatisticsExamplesRow formatOverlap checkUse and files

Where the pairs come from

No ground truth was created for this probe. Each target is the source dataset's own edited image, used unchanged. Neither source has real-photo targets.

What the targets ask for

Edit size is the mean absolute pixel change from input to target (RGB in 0–1, both resized to 512×512). The dashed line marks 0.03, the threshold the diagnosis uses to call a model output "no edit".
